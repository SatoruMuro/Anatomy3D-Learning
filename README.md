# Anatomy3D Learning

**Interactive 3D anatomy learning resources by Satoru Muro**

Anatomy3D Learning は、3Dモデルを用いて人体解剖をインタラクティブに学ぶためのWeb教材です。

医学・医療系学生、医療従事者、解剖学を学ぶ方を対象に、テーマごとの3D解剖教材を公開しています。

## Online Learning Site

https://satorumuro.github.io/Anatomy3D-Learning/

## Available Lessons

### 女性骨盤底の基本 3D解剖

**Female Pelvic Floor — Basic 3D Anatomy**

女性骨盤底の基本的な骨・筋の位置関係を、インタラクティブな3Dモデルで観察できます。

今後、さまざまな解剖学テーマの教材を追加予定です。

## About this repository

This repository hosts the files used for the public **Anatomy3D Learning** website.

The original high-resolution 3D source data are not included in this repository.

## 3D Model Usage

The 3D models published through Anatomy3D Learning are provided for **online educational viewing**.

Unless explicit permission is granted, extraction, redistribution, conversion, modification, or reuse of the published 3D model data is not permitted.
