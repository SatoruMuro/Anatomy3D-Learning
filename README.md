# Anatomy3D-Learning Pages

「女性骨盤底の基本 3D解剖」の公開用GitHub Pages artifactです。

このリポジトリには、Webアプリのproduction buildとWeb閲覧専用の低精細Public Web Derivative GLBだけを収録しています。原版STL、private asset、高精細derivative、変換前の3Dデータは含まれていません。

公開サイト:

https://satorumuro.github.io/Anatomy3D-Learning/

## 3D Model Policy

The original STL data are not included in the public site.

Public GLB files are reduced-resolution derivatives for educational web viewing.

Extraction, redistribution, conversion, or reuse of the published 3D model data is not permitted.

ブラウザで3D表示する以上、meshの取得を技術的に完全防止することはできません。本repositoryでは、公開meshをWeb閲覧専用の低精細derivativeへ限定し、ファイル名をmanifest参照の匿名名にしています。ファイル名の匿名化は補助策であり、保護の本体はresolution reductionです。
